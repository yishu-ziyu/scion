# Contributing to 持节

This repository is a **personal product graft**, not the public Nanobrowser community repo.

## For work on 持节

1. Edit in this repository root.
2. Commit from this root to `origin` (`yishu-ziyu/scion`).
3. Follow [AGENTS.md](./AGENTS.md).

```bash
pnpm install
pnpm build
pnpm -F chrome-extension test
```

## Upstream Nanobrowser

Contributions intended for upstream Nanobrowser should go to
https://github.com/nanobrowser/nanobrowser — not this remote.
