# 021 — 长程任务 Agent 北极星

## 状态

**current，Owner 已确认。** 本文件取代旧的“浏览器操作演示 + 强制审批”叙事。旧方向保留为历史文档，不再作为当前北极星。

## 一句话

持节是一个运行在用户 Chrome 里的**长程任务 Agent**：用户交出一个自然语言目标，Agent 自己拆计划、跨页面/站点执行、记住上下文、完成可验证交付。

## 用户要看到的效果

1. 用户只给一次任务，例如“调研 10 家竞品，输出对比表和一份结论”。
2. Agent 先给出简短计划，然后开始自主执行。
3. 执行过程中展示当前阶段、已找到的关键结果、下一步，不要求用户逐动作确认。
4. 任务完成后给出可检查的成果：表格、报告、文件、页面状态或回执。
5. 用户随时可以停止、追问、修正；停止不代表每一步都要批准。

## 能力定义

### 长程

- 任务可能跨多个页面、多个站点、多轮观察，长度以“目标完成”为准，不以单页面操作为边界。
- 必须有持久化计划：阶段、子目标、检查点、验收条件。
- 中断后应能从计划中恢复，而不是从零开始。

### 复杂

- 需要多步推理、信息收集、结果整理和交付物生成。
- 不是“打开某个页面”或“暂停视频”这类单动作捷径。
- 单动作捷径可以作为内部工具，但不是产品核心。

### 自主

- 任务级授权：用户提出目标即授权目标内的行动。
- 不弹强制批准，不因“外部提交”打断。
- 超范围高风险动作才说明；敏感输入仍直接拒绝自动处理。

### 可验证

- 中间检查点和最终结果都必须有可观察证据。
- 模型说“完成”不算完成；证据不足时诚实失败。
