# 第 16 章：资源感知优化（Resource-Aware Optimization）

## 书里的机制

- 运行中按计算、时间和钱做取舍，不是只排动作顺序（「在指定的资源预算内达成目标或优化效率」）。
- 简单请求走更快更便宜的模型，复杂请求走更贵更准的模型（「简单查询使用更小、更经济的 LLM」；「Gemini Flash」对「Gemini Pro」）。
- 先分类再选路：`simple` / `reasoning` / `internet_search`，或按查询长度把短句交给便宜模型（「三个类别是: simple、reasoning、internet_search」；「query_length < 20」）。
- 首选模型过载或限流时切到备用/更经济模型，而不是整单失败（「当首选模型因过载或限流而不可用时」；OpenRouter「顺序模型回退」`models: [...]`）。
- 批评智能体审回答质量，并间接改路由（「将简单查询定向到 Pro 模型或将复杂查询定向到 Flash 模型」）。
- 提示要剪：摘要历史、少送 token（「上下文修剪和摘要」；「最小化提示词 token 计数」）。
- 选工具时也看 API 费用、延迟、耗时（「自适应工具使用和选择」；「API 使用成本、延迟和执行时间」）。
- 另外还有：预估负载、多智能体通信成本、省电、并行、从反馈学分配、优雅降级（「主动资源预测」到「优雅降级和回退机制」）。

## 结论

- 部分做成
- 完成度：48
- 一句话：`decideUserTurn` → `resolveUserTurnCheap` 和 `createLlmControlDriver` → `buildLongHorizonContext` / `SkillRuntime.tryDecide` 已在生产主路径上省调用、省上下文、省步数；搜 `QueryRouter`、`openrouter/auto`、`internet_search` 在 `chrome-extension/src` 与 `pages/side-panel` 无命中，循环里始终是同一个 Navigator 模型，没有按难度换便宜模型。

## 对持节业务的意义

用户把页面上的事交出去，侧栏按发生的事往下长，最后交出能对页核对的那一句。

这一章会改的是：用户刚说「你好」时，侧栏立刻回一句、不启动浏览循环；以及模型在同一页空转时，侧栏用「试了多轮还没做成」停住，而不是一直烧步骤。

缺的那一块用户今天碰不到：同一条「打开 YouTube 看第一个」和一条要推理的长任务，用的是设置里同一个 Navigator 模型；限流也不会换成更便宜的备用模型。

`settleProposedDone` 在每次自称做完时再打一轮监督模型。这花钱换「别假完成」，符合持节「能核对」，但和书里「用批评去改便宜/贵路由」不是一件事。

设置页的「单一任务的步骤上限」是用户能拧的唯一资源旋钮。拧小了，长任务会更早停在「试了多轮还没做成」。

## 完成方案

- Goal: 生产主路径在「正则/Skill 能定」时继续零控制模型；在 Navigator 返回 429/超时/不可用时，用设置里第二个已配置模型再打一次，而不是同一模型空转到 `max_steps`。不新开第二套 agent 树。
- Hard bar:（when I do X, I see Y）我说「你好」，侧栏仍只有「你好，需要我帮你在页面上做什么？」且 `control_llm_invoke` 不出现（现有）。我把 Navigator 配成会 429 的端点、并在设置里填好备用模型后发出「打开 example.com」，任务继续用备用模型打开页面，而不是直接「试了多轮还没做成」。
- 改哪些现有文件（不要新开第二套 agent 树）
  - `chrome-extension/src/background/agent/helper.ts`：一次调用失败且 `classifyRetry === 'retry'` 时，用已存的第二个 `ModelConfig` 再 `createChatModel`。
  - `chrome-extension/src/background/agent/backends/control-llm.ts`：`llm.invoke` / `supervisorLlm.invoke` 走上述回退；不要为路由再写一个 Agent 类。
  - `packages/storage` 的 agent 模型设置：给 Navigator 增加可选备用模型名（用户在现有模型设置里填，不新做仪表盘）。
  - 非必须：`user-turn-decision.ts` 的模糊句分类若仍要模型，可复用同一备用小模型；分类结果仍是 `reply|clarify|execute|stop`，不要引入书里的 `simple/reasoning/internet_search` 三套执行器。
- 非目标: OpenRouter `openrouter/auto`、Google ADK 路由器/批评多智能体、侧栏费用数字、按电池/负载预测、用批评去微调路由、把 `planner.ts`/`navigator.ts` 当便宜模型重新接上（`factory.ts` 生产走 `createLlmControlDriver`）。
