# 第 17 章：推理技术（Reasoning Techniques）

## 书里的机制
- 高级推理不是一次吐答案，而是给模型更多步、更长时间去拆问题、看中间步、再下结论。（「这些高级方法的核心原则是在推理过程中分配更多的计算资源」）
- 思维链（CoT）：不要直接给答案，先写出中间推理步骤；可用少样本，或只说「逐步思考」。（「CoT 提示词不是要求模型直接给出答案，而是引导其生成一系列中间推理步骤」）
- 思维树（ToT）：在 CoT 上分叉多条中间路径，评估后再定答案，允许回溯和换路。（「它允许 LLM 通过分支到不同的中间步骤来探索多个推理路径，形成树状结构」）
- 自我纠正：对照原要求审查草稿，指出缺口，再写出修订稿。（「它涉及起草、根据原始要求进行审查以及实施具体改进的迭代循环」）
- 自一致性 / 推理扩展：同一题生成多个候选（多样本或束搜索），再用选择机制挑更好的；小模型加思考预算有时能超过更大、更省步的模型。（「指示模型生成多个潜在答案——可能通过多样化束搜索或自一致性方法等技术——然后使用选择机制来识别最优输出」）
- ReAct：思考、行动、观察交错；行动是调工具，观察再喂回下一轮思考。（「这个循环重复进行，每个观察通知下一个思考」）
- 程序辅助（PALMs）：模型写代码，交给确定性运行时算，再把结果说成人话。（「这种集成允许 LLM 在问题解决过程中生成和执行代码」）
- 再往上还有：可验证奖励训练出的长思考模型（RLVR）、多模型辩论（CoD / GoD）、自动搜提示与拓扑（MASS）、以及带时间预算的 Deep Research（搜 → 找缺口 → 再搜 → 综合）。（「用户为 AI 分配一个复杂的查询并授予它一个『时间预算』」）

## 结论
- 部分做成
- 完成度：36
- 一句话：`createLlmControlDriver` → `runObserveActLoop` 做成了观察-决定-行动-再观察，但 `renderControlSystemPrompt` 要求只输出一个 JSON、`removeThinkTags` 丢掉 `<think>`，`TaskStatusCard` 调 `deriveWorkStream` 时不传 `currentSummary`，书里的逐步思考 / 自一致性 / 思维树没有做成。

## 对持节业务的意义
持节的用户操作是：把当前页上的事交出去，侧栏按发生的事往下长，交出能核对的结果。
本章改的是模型被怎么要求「想」，以及用户能不能看见想的过程。
今天用户交「打开报名页并比对入口」时，失败点是 `runObserveActLoop` 走错一次点击、或 `no_progress` 停住；侧栏长出打开的页，不长出「为什么点这一条」。
声称做完时，`settleProposedDone` 会再看一页：页面上对不上就打回，用户可能看到「正在核对页面上的结果」或「还没做完」。
难的多跳问答没有多样本、没有第二条思路树；模型自带的 `<think>` 被剥掉，也不能当核对材料。
把 CoT 整段铺进侧栏会和 `task-progress-view.ts` 的设计打架（Now 行明确不要 chain-of-thought）。要补的是一句可核对的「这一步为什么」，不是第二套推理框架。

## 完成方案
- Goal: 生产 decide 仍只出 JSON；把未完成时的短 `observation`（或单独短 `rationale`）接到侧栏已有的「思考过程」折叠；监督继续只核对页面是否做完。
- Hard bar: when I 在侧栏交出「打开 A 再比对报名入口」, I see 「思考过程」里有一句本轮读页/理由（不是空白、也不是「思考中」），最后仍交出能对照页面核对的那一句。
- 改哪些现有文件（不要新开第二套 agent 树）：
  - `chrome-extension/src/background/agent/backends/control-policy.ts`：`CONTROL_SYSTEM_PROMPT_BODY` / `parseControlPolicyDecision` 让未完成时的 `observation` 必须是一句短读页（或加可选 `rationale`），仍禁止 JSON 外散文。
  - `chrome-extension/src/background/agent/backends/control-llm.ts`：decide 产出 action 时把该句交给 Task 钩子（不要只留在模型上下文的 `lastActionMemory`）。
  - `chrome-extension/src/background/task/manager.ts`（或 `ActionAttempt` 写入处）：把这一句存成侧栏能读的字段。
  - `pages/side-panel/src/components/TaskStatusCard.tsx`：`deriveWorkStream({ currentSummary })` 传入该句（`work-stream.ts` `thinkingText` 已过滤「思考中」等噪声）。
- 非目标: 思维树、自一致性 n 次采样、CoD/GoD 辩论、MASS 搜拓扑、PALM 代码沙箱、把 `planner.ts` / `navigator.ts` 请回生产路径、把 `<think>` 原文铺进侧栏、Deep Research 独立产品面。
