## 用户可见（一句）

侧栏从「聊天流 + 假运行」收成 **Mission → 计划 → Now → Health → 成果/审计** 控制台；任务进行中对话默认折叠；暂停/继续固定在 composer 旁，停止降级到「更多」。

## 切片对照

| 切片 | 可观察行为 | 主要路径 |
|------|------------|----------|
| **S1**（已落地） | Health 固定行；非 running 无「思考中…」shimmer；site chip 仅 running | `task-progress-view` / Overview / ThinkingReasoning |
| **S2** | running 时 `task-progress-current-activity`：动作摘要 + 服务于某阶段 + 可选站点 | `deriveCurrentActivity` + Overview Now 区 |
| **S3** | 无 durable gate 时不显示 phase 比例 pie / `x/y 阶段`；改显示「N 里程碑」 | `MissionPlanList` `durableProgress` / `data-durable-progress` |
| **S4** | 活跃任务 + 有消息时 `data-collapsed=true`，折叠条「对话 N 条」 | `SidePanel` `chat-log-fold` |
| **S5** | type ladder（xs–lg）+ space ladder（1–5 / section）+ weights | `chijie-tokens.css`；Now/Health/composer 消费 |
| **S6** | composer 旁 `composer-pause` / `composer-resume`；`composer-stop` 在更多菜单；卡片内仅「调整方向」（interrupted 保留紧凑恢复） | `SidePanel` `composer-continuous-controls`；`TaskStatusCard` 降级 continuous |

## Done（可证伪）

1. When 任务 `running` 且有 attempt → 见 Now 摘要（如动作文案）+ purpose「服务于…」；Health「正常推进」。
2. When 任务非 running → 无 `currentActivity` / 无 Now 块。
3. When generic 计划无 gate target → `data-durable-progress="false"`，无 `chijie-plan-head-pie` 作假进度。
4. When 活跃任务有消息 → 聊天默认折叠；点「对话 N 条」展开。
5. When running → composer 见暂停；paused/interrupted → 见继续；停止在「更多」内。
6. 无「批准一次」/逐步审批主路径（004 保持）。
