# 持节 (Chijie)

Product name for this Chrome extension fork (formerly Nanobrowser / briefly 奕枢).

## Etymology

**持节** — classical office of the envoy: one who **holds the credentials (节)** and acts with the sovereign's mandate.

- 《汉书》等：使节出疆，持节专对。
- Product mapping: the user is the principal; the agent holds temporary authority to operate the browser under task-scoped autonomy; **verified completion** is reporting back with evidence.

| Layer | Name |
|-------|------|
| Product (UI / Chrome) | **持节** |
| English short | **Chijie** |
| Repo | [yishu-ziyu/scion](https://github.com/yishu-ziyu/scion) |
| Extension dist | `./dist` |

## One-liner

Personal **long-horizon task agent**: mission/plan-based web tasks in daily Chrome, task-scoped autonomy, verified delivery only.
